# Requirements

This project uses only Python standard library modules, so no external dependencies are required for the core implementations.

However, for development and testing, the following are recommended:

```
pytest==7.4.3          # Testing framework
pytest-cov==4.1.0      # Code coverage
black==23.12.0         # Code formatter
flake8==6.1.0          # Linter
pylint==3.0.3          # Code analysis
mypy==1.7.1            # Type checker
```

## Installation

### For Users (No external dependencies)
```bash
git clone https://github.com/trailmail123456/dsa-mastery-.git
cd dsa-mastery-
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### For Developers
```bash
git clone https://github.com/trailmail123456/dsa-mastery-.git
cd dsa-mastery-
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Python Version

- **Minimum**: Python 3.8
- **Recommended**: Python 3.10+

## Running Tests

```bash
# Run all tests
pytest

# Run with coverage
pytest --cov=.

# Run specific test file
pytest tests/test_algorithms/test_sorting.py
```

## Code Quality

```bash
# Format code with Black
black .

# Check with Flake8
flake8 .

# Type checking
mypy .

# Linting
pylint data_structures/ algorithms/
```
