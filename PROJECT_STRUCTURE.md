## How to Navigate

1. **Start with Data Structures** - Understand the fundamentals first
2. **Move to Algorithms** - Learn different problem-solving approaches
3. **Practice Problems** - Apply your knowledge to real-world scenarios
4. **Review Complexity** - Analyze Time and Space complexity

Each file should include:
- Clear docstrings
- Time and Space complexity analysis
- Example usage
- Test cases
